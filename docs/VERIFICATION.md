## 需要外部配置或尚未验证

- 未使用任何真实大模型 Key，因此未验证实际供应商的计费、模型权限和生成内容质量。翻译、摘要、LLM 关键词提取需运行者自行配置；基础业务不依赖这些外部调用。
- 已提供 Dockerfile、Nginx 与 Compose 配置，但本机 Docker Engine 未运行，未执行容器构建与整栈启动。已实际验证的是本机 JAR、MySQL 与前端生产构建路径。
- 未进行浏览器逐页交互回归、SSE 实时推送端到端验证、性能压力测试及全面渗透测试。
- 本机 Java 21 的 Windows 隔离环境不支持默认 Unix socket 回环。测试启动时将 `jdk.net.unixdomain.tmpdir` 指向不存在的测试子目录，促使 JDK 使用 TCP 回环；此兼容参数未写入应用或容器默认配置。

## 迁移处理

- 新仓库只接收清理后的源码快照，以独立首次提交开始，不复制旧 Git 历史。
- API Key、数据库密码和 JWT 签名密钥改为环境变量；密钥缺失/过短时阻止启动。
- 移除测试 HTTP 文件中的完整 JWT；不携带 MySQL 数据目录、私钥、日志和业务数据。
- 保留 11 张表的结构初始化脚本，去除自动 DROP TABLE，避免初始化时删除既有数据。
- 补充可执行 JAR 打包、修复 Linux Maven Wrapper，补充本机与容器运行说明。
- 关闭 MyBatis SQL 参数日志，避免日志记录数据库密码哈希或邮件内容；接口不向客户端回传内部异常详情。
- 修正联系人删除的归属校验，以及通知查询使用当前登录用户身份。
- 旧仓库已公开凭据的撤销/轮换仍需凭据持有人在对应服务执行，新仓库迁移不能撤销这些凭据。
